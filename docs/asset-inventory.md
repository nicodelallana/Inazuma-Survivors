## Import gate

For every selected file, record its exact path, creator/source, format/dimensions, animation metadata, permission text/date/conditions, attribution, and destination path. The Inazuma Rogue README says its playable folder includes assets extracted from original commercial games. A repository creator's permission should not be treated as permission from those underlying rights holders. If the file's rights cannot be established, do not import it; use an original placeholder instead. Keep references and any downloaded inspection copy outside the destination repository.
